# 历史价格查询

路径：`/supply-chain/analysis/price-query`

## 功能说明

- 本页用于按物料查询历史报价和历史采购价格，不是采购订单情况表，也不写回任何价格数据。
- 顶部按钮：打印统计报表、查询内容、列设置、导出信息。
- 查询条件：开始日期、结束日期、供应商、物料编码、物料名称、规格、只显示有价格记录。
- 开始日期默认最近三个月当天，结束日期默认今天；两个日期和物料编码必填，开始日期不能大于结束日期。
- 物料编码按 `UB_ERP_Bom_000.kcaa01` 远程联想，只显示物料编码；选择后带出名称和规格，也允许手动输入编码查询。
- 查询时显示加载进度浮层，包含等待秒数、滑动进度条和后台仍在查询提示。
- **点行展开（2026-07）**：左边展开箭头列已全局隐藏；点主表物料行即可展开/收起历史价格子表（点展开区内不误收）。

## 数据口径

- 基础物料来自 `UB_ERP_Bom_000`，只取 `del=0/pass=1`。
- 物料字段：材料编码 `kcaa01`、材料名称 `kcaa02`、规格 `kcaa03`、BOM单位 `kcaa29`、BOM价格 `sale_price`、采购单位 `kcaa25`。
- 报价价格来自 `UB_ERP_Buy_offer` + `UB_ERP_Buy_offer_list`，按 `cgaa01 = cgab01` 关联；日期取 `cgaa02`，供应商取 `cgaa04`，价格取 `cgab04`，税率取 `Tax`。
- 采购价格来自 `UB_ERP_Buy_order` + `UB_ERP_Buy_order_list`，按 `kcaj01 = kcak01` 关联；日期取 `kcaj02`，供应商取 `kcaj05`，价格取 `kcak04`，税率取 `Tax`。
- 报价和采购主表第一期只取未删除、已审核记录；明细只取未删除记录。
- 含税价格 = `价格 + 价格 * Tax`；历史数据若 `Tax` 大于 1，按百分数处理为 `Tax / 100`。
- 同一物料下报价和采购记录合并后按价格日期倒序显示，第一条标记为“最近价格”，其余为“历史价格”。
- 未勾选“只显示有价格记录”时，无价格物料仍显示，并展示“无历史价格”。

## 权限

- 查看接口走 `supply-chain/analysis/price-query:view`。
- 本报表价格列不单独走 `price` 权限；有查看权限即可查看价格、含税价格、打印和页面展示。
- 导出按钮走 `supply-chain/analysis/price-query:export`。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/history-price-query/print-header` | 读取打印抬头 |
| GET | `/api/history-price-query/supplier-options` | 供应商候选 |
| GET | `/api/history-price-query/material-options` | 物料编码候选 |
| GET | `/api/history-price-query/report` | 拉取历史价格查询报表 |

## 性能口径

- 第一版强制物料编码必填，禁止默认全量物料历史价格查询。
- 后端先按 BOM 物料条件圈定物料集合，再按当前物料集合批量查询报价和采购价格。
- 报价和采购价格用 `UNION ALL` 合并，不做逐物料循环查价，不使用全局中间表。
- 本期不新增数据库索引；如后续真实数据仍慢，再单独确认索引方案。
