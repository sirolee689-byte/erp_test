# 采购订单情况表

路径：`/supply-chain/analysis/order-status`

## 功能说明

- 本页用于统计采购订单执行情况，不是采购订单录入页，也不是采购入库明细表。
- 顶部按钮：打印统计报表、查询内容、列设置、导出信息。
- 查询条件包含查询开始日期、查询结束日期、供应商、采购单号、材料代码、材料名称、材料规格、包含未结案、只显示送货相差数。
- 查询开始日期、查询结束日期必填，且开始日期不能大于结束日期。
- “包含未结案”第一期只保留查询项和参数，不参与主查询过滤，避免在结案字段未确认前误过滤数据。
- 查询结果按供应商分组展示，底部显示总计；差数为负数时用异常样式标记。

## 数据口径

- 主行来源：`UB_ERP_Buy_order` + `UB_ERP_Buy_order_list`，按 `kcaj01 = kcak01` 关联。
- 基础条件：采购主表 `del=0`、采购明细 `del=0`、采购日期 `kcaj02 >= 开始日 00:00:00` 且 `< 结束日次日 00:00:00`。
- 本报表不强制采购主表 `pass=1`；未审核采购单仍展示，并在采购单号旁显示“未审”。
- 供应商按采购主表 `kcaj05` 精确筛选；采购单号按 `kcaj01` 模糊筛选；材料选择优先按采购明细 `systemcode` 精确匹配。
- 采购数量按 `kcak03`、`kcaa26`、`kcaa27` 换算到使用单位；换算字段异常时按原始采购数量统计，并显示异常提示。
- 已审核入库数量和入库未审数量来自采购入库主从表，按采购单号 `kcan04` 和明细 `GUID` 关联采购明细 `GUID`，数量取 `kcao031`。
- 采购退货数量来自采购退货出库，按 `kcap03=1`、`kcap04=采购单号`、明细物料编码 `kcaa01` 汇总 `kcaq03`。
- 入库金额按已审核入库含税金额 `kcao051` 减已审核采购退货含税金额 `kcaq051`。
- 差数 = 换算后采购数量 -（已审核入库数量 - 采购退货数量）；入库未审数量只展示，不参与差数。

## 权限

- 查看接口走 `supply-chain/analysis/order-status:view`。
- 入库金额列走 `supply-chain/analysis/order-status:price`；管理员始终可见。
- 导出按钮走 `supply-chain/analysis/order-status:export`。
- 无金额权限时，页面、打印、导出不显示入库金额，后端也不返回入库金额字段。
