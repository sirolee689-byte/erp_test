## 当前页面说明

- 页面顶部不再放输入框，改为两行按钮：
  - 第一行只保留：`物料单统计表（明细）`、`物料单统计表（汇总）`；未选中为默认白底按钮，当前页签选中后变蓝色。
  - 第二行为：`打印统计报表`、`查询内容`、`列设置`、`导出信息`
- `查询内容` 现在直接打开“选择 PI”弹窗（一步到位，不再先开中间条件弹窗再点“选择”）。
- PI 选择弹窗交互与采购订单添加页（采购类型=订单采购）一致：
  - 顶部检索：`PI号 / PO号 / 客户`
  - 列结构：`操作 / PI号 / PO号 / 客户`
  - 分页：服务端分页（总数、每页条数、页码、跳页）
- 新增 `颜色` 列，位置在 `编码` 右边；明细、汇总、打印、导出口径保持一致。
- 字段口径：
  - 颜色：来自 `UB_ERP_Bom_pi_cost.kcaa11`；空值保持空。
  - 搭配：优先取 `UB_ERP_Bom_pi_cost.bnfo`（历史库兼容 `binfo`），为空再回退 `Describe`。
  - 汇总页颜色：同编码同搭配合并时，多个颜色做去重后按逗号拼接展示。
- 列设置会同步影响屏幕表格、打印和导出，并写入浏览器本地存储。
- 选中 PI 后会立即执行查询并刷新当前明细/汇总页签数据。
