# 物料单

路径：`production/analysis/material-sheet`

## 当前页面说明

- 页面顶部两行按钮：
  - 第一行模式：`物料单统计表（明细）`、`物料单统计表（汇总）`、**外协清单**、**位置裁片清单**；未选中为默认白底，当前模式选中后变蓝色。
  - 第二行为：`打印统计报表`、`查询内容`、`列设置`（外协清单/位置裁片清单模式隐藏）、`导出信息`
- **明细/汇总**：`查询内容` 直接打开“选择 PI”弹窗；选中后立即加载物料单。
  - PI 选择弹窗交互与采购订单添加页（采购类型=订单采购）一致。
  - 接口仍用 `GET /api/buy-order/pi-options`；门禁为「采购订单查看」或「物料单查看」任一即可。
- **外协清单（第一期）**：
  - 入口：汇总右侧「外协清单」。
  - `查询内容` 打开专用条件弹窗：统计开始/结束日期（必填，默认近三年：开始=三年前、结束=今天）、PI号（可选，可联想已审销售订单）、PO号（可选手输）。
  - PI、PO 都为空时先确认「将按日期范围查大量数据」再继续。
  - 报表按 PI 分块，表头 PI/PO/日期；块内按销售明细厂款分块（厂款号=`kcaa01`，并用于匹配 `pi_cost.pq`；客款号/组别/订单量），下列外协材料。
  - 材料只取 `UB_ERP_Bom_pi_cost` 且 `kcaa13=1`、`isok=1`；按编码+颜色+名称+规格合并，`SUM(kcac06)` 为单个用量，合计=`单个用量×订单量`；颜色 JOIN `UB_ERP_Stocks_colorcode`。
  - 「位置 / 裁片物料皮名及颜色」按 PI+厂款匹配 `UB_ERP_Bom_Sales_list` 的 `CUT-` 行及下级材料。
  - 接口：`GET /api/production/material-sheet/outsourcing-list`；权限同物料单查看（或销售订单查看）。
  - 支持浏览器打印与 Excel 导出；**不做 PDF 导出**。第一期不开放客户筛选、类型切换、搭配显示。
- **位置裁片清单（第一期，含非外协）**：
  - 入口：外协清单右侧「位置裁片清单」。
  - 查询条件弹窗与外协清单共用交互（日期必填默认近三年、PI/PO 可选、都空要确认）；标题区分。
  - 按 PI→厂款展示一张材料表：先 Part1 `UB_ERP_Bom_pi_cost`（`isok=1`，**不限** `kcaa13`）并算位置/裁片皮名（CUT 口径同外协清单）；再追加 Part2 销售 BOM 下级 `kcaa13=1`（`sid=xsak01`、`kcac01=xsak02`），位置/皮名固定 `-`；两段不去重。
  - 厂款块底部「合计数量」= 该厂款全部展示行合计累加。
  - 接口：`GET /api/production/material-sheet/cut-position-list`；权限同物料单查看（或销售订单查看）。
  - 支持浏览器打印与 Excel；**不做 PDF**。第一期不开放客户/类型/真实用量口径。
- 新增 `颜色` 列（明细/汇总），位置在 `编码` 右边；明细、汇总、打印、导出口径保持一致。
- 字段口径（明细/汇总）：
  - 颜色：取 `UB_ERP_Bom_pi_cost.kcaa11`，再按 `UB_ERP_Stocks_colorcode.code` 带出中文名，展示「编码,中文名」。
  - 搭配：优先 `bnfo`（历史库兼容 `binfo`），为空再回退 `Describe`。
  - 汇总页颜色：同编码同搭配合并时，多色去重后用分号 `;` 拼接。
- 「单物料合计」列仅出现在**明细**页签；**汇总**、外协清单与位置裁片清单不提供。
- 列设置会同步影响明细/汇总屏幕表格、打印和导出，并写入浏览器本地存储。
- 明细/汇总表格数据行不再使用斑马纹，仅保留悬停高亮。
- 列宽 DIY：损耗用独立类 `.col-loss`（默认 `70px`），用量/合计/单物料合计仍共用 `.col-num`（默认 `90px`）。

## 已知边界

- 明细/汇总查询仍以 PI 号为主（必填），不会做全量无条件查询。
- 外协清单 / 位置裁片清单可按日期无 PI/PO 查询（有确认）；数据量大时可能较慢。
- 业务数据口径未改，仍使用销售订单一键运算后写入的成本价物料表。
