# 物料单

路径：`production/analysis/material-sheet`

## 当前页面说明

- 页面顶部不再放输入框，改为两行按钮：
  - 第一行只保留：`物料单统计表（明细）`、`物料单统计表（汇总）`；未选中为默认白底按钮，当前页签选中后变蓝色。
  - 第二行为：`打印统计报表`、`查询内容`、`列设置`、`导出信息`
- `查询内容` 现在直接打开“选择 PI”弹窗（一步到位，不再先开中间条件弹窗再点“选择”）。
- PI 选择弹窗交互与采购订单添加页（采购类型=订单采购）一致：
  - 顶部检索：`PI号 / PO号 / 客户`
  - 列结构：`操作 / PI号 / PO号 / 客户`
  - 分页：服务端分页（总数、每页条数、页码、跳页）
  - 接口仍用 `GET /api/buy-order/pi-options`；门禁为「采购订单查看」或「物料单查看」任一即可（仅有物料单查看权也可打开选 PI，不必再开采购订单权限）。
- 新增 `颜色` 列，位置在 `编码` 右边；明细、汇总、打印、导出口径保持一致。
- 字段口径：
  - 颜色：取 `UB_ERP_Bom_pi_cost.kcaa11`，再按 `UB_ERP_Stocks_colorcode.code` 带出中文名，展示同 BOM 资料：`编码,中文名`（无中文名则只显示编码）。
  - 搭配：优先取 `UB_ERP_Bom_pi_cost.bnfo`（历史库兼容 `binfo`），为空再回退 `Describe`。
  - 汇总页颜色：同编码同搭配合并时，多个颜色去重后用分号 `;` 拼接（例：`419,深灰色;580,黑色`）。
- 「单物料合计」列仅出现在**明细**页签（含列设置、表格、打印、导出）；**汇总**页签不提供也不显示该列。
- 列设置会同步影响屏幕表格、打印和导出，并写入浏览器本地存储。
- 选中 PI 后会立即执行查询并刷新当前明细/汇总页签数据。
- 明细/汇总表格数据行不再使用斑马纹（奇偶行同色），仅保留悬停高亮。
- 列宽 DIY：损耗用独立类 `.col-loss`（默认 `70px`），用量/合计/单物料合计仍共用 `.col-num`（默认 `90px`）；改页面底部样式即可。

## 已知边界

- 目前查询条件仍以 PI 号为主（必填），不会做全量无条件查询。
- 业务数据口径未改，仍使用销售订单一键运算后写入的数据表。
