# 智能饭堂 · 统计报表

## 页面范围

- 顶部固定为“每天订餐情况表、订餐未刷卡明细、月报餐统计表、消费汇总”，四项均已开放。
- 报表共用白底标题、浅灰查询条和“确定统计 / 导出信息”按钮样式；导出需要当前页面 `export` 权限。
- 每天订餐情况表默认查询当天；其余三个报表首次打开不自动查询。

## 每天订餐情况表

- 按单个日期展示全部有效报餐员工；同一员工一天一行，午餐、晚餐分别以蓝色“√”标记。
- 双栏连续序号展示；不分页。日期选择框强制 140px。
- 导出文件为 `每天订餐情况表-YYYY-MM-DD.xlsx`。

## 订餐未刷卡明细

- 查询条为时间范围、月份快捷回填、部门、确定统计和导出信息；三个日期选择框均强制 140px。
- 只显示有效报餐但没有正式刷卡的员工餐次；按员工+日期+餐别合并旧系统多菜记录。
- 待审核补录不计入正式刷卡。
- 导出文件为 `订餐未刷卡明细-开始日期_结束日期.xlsx`。

## 月报餐统计表

- 选择 `YYYY-MM` 后，按每个自然日展示午餐、晚餐的总数、员工餐和管理餐；没有数据的日期显示 0。
- 月份框强制 140px，午餐和晚餐之间保留窄空白列。
- 导出文件为 `月报餐统计表-YYYY-MM.xlsx`。

## 消费汇总

- 查询条完全复刻订餐未刷卡明细：时间范围、月份快捷回填、部门、确定统计和导出信息。
- 名单来自员工档案 `del=0、pass=1` 的全部在职已审核员工；未选择部门时，即使该员工所选期间没有报餐和消费也显示一行 0。选择部门时按员工档案 `in_bm` 精确筛选。
- 列顺序固定为：序号、员工编号、员工名称、报（午餐）、午餐、补餐（午）、午餐金额、有报餐无消费金额（午）、报（晚餐）、晚餐、补餐（晚）、晚餐金额、有报餐无消费金额（晚）、有报餐未消费、有报餐有消费、补餐总数、总计、可补贴金额、代扣餐费；页面和 Excel 导出保持一致。
- 员工编号优先 `new_code`，为空回退 `code`。报餐与正式消费均按员工+日期+餐别去重；优先按 `uid=staff.id` 关联，历史缺失时回退新旧员工编号和新旧卡号。
- 正式消费为 `meal_log.del=0`；其中 `bl=1` 为已审核人工补餐，既计入午餐/晚餐，也计入对应补餐列。待审核补录 `bl=1、del=1` 不计入。
- 午餐、晚餐金额分别为消费次数乘 5；无消费金额为报餐次数减消费次数后乘 5，不对负数归零。有报餐未消费/有消费按报餐与正式消费的餐次交集计算；补餐总数、总计、可补贴金额和代扣餐费按页面定稿公式计算。
- 本报表不修改补录保存规则，不统计菜式，不新增数据库表、字段或索引。

## 接口

- `GET /api/canteen/reports/daily-orders?date=YYYY-MM-DD`
- `GET /api/canteen/reports/missed-swipes?startDate&endDate&department`
- `GET /api/canteen/reports/missed-swipes/departments`
- `GET /api/canteen/reports/monthly-orders?month=YYYY-MM`
- `GET /api/canteen/reports/consumption-summary?startDate&endDate&department`

以上接口均要求 `canteen/reports:view`。不新增数据库表、字段或索引。
