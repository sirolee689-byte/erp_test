# 智能饭堂管理

ERP 路径：`canteen/management`，需要饭堂管理权限。

- **系统配置**：维护报餐截止 `bc`、午餐 `two1/two2`、晚餐 `three1/three2` 打卡时间，以及 `UB_ERP_Dining_machine` 的授权 IP。
- **报餐配置**：先选择 `YYYYMM` 并生成本月默认规则。列表以月份为父行、特殊日期为默认展开的子行；只有已准备月份可报餐，工作日默认可报、周六日默认不可报。特殊日期支持同月单日或连续日期，并可设为“可报餐/不可报餐”；日期不可重叠。
- **特定设置**：可对部门或员工设置常设、临时开放；仅在已准备月份的禁报日期生效。
- 普通饭堂管理员可新增、编辑；只有 `New_UB_ERP_User.is_admin=1` 的超级管理员可删除月份准备或特殊日期。删除月份时同时删除该月特殊日期。

员工端读取与提交报餐共用同一套后端日期规则。法定节假日、调休不再内置控制；已提交的报餐不会因后续配置调整而自动取消。
